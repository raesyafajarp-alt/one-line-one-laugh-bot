# One Line, One Laugh

Entry for make.fun competition `u-plucky-finch-20-one-line-one-laugh-0ffe66ea` — "One Line, One Laugh" (free, $2 pool).

## The entry

> I asked my smart speaker for life advice. It said "I'm sorry, I didn't quite catch that" — the most honest answer I've ever received.

(133 characters, one line, no setup needed.)

## What the program does

`main.py` writes that single funny line to `/output/entry.txt` (UTF-8, 1–200 characters, as the competition gate requires). It asserts the length is in range before writing.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```
